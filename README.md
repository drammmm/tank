# 坦克大战 · Tank Battle

一个用 **HTML5 Canvas** 编写的经典《坦克大战》(Battle City) 风格小游戏，单文件、零依赖，打开即玩。

A classic *Battle City*-style tank game written in pure HTML5 Canvas. Single file, zero dependencies.

## ✨ 功能特性 Features

- 🎮 经典玩法：控制己方坦克，消灭敌人、保护基地
- 🧱 多种地形：砖墙（可摧毁）、钢墙（不可摧毁）、河流（不可通行）、树林（可藏身）
- 🤖 4 种敌人：普通、快速、重火力、装甲（需多次命中）
- 💣 多种道具：⭐ 强化火力、🛡 护盾、❤ 加命
- 📈 无限关卡，难度递增，最高分本地保存
- 🔊 Web Audio 音效（射击 / 命中 / 爆炸 / 拾取）
- 🖥 像素风格渲染，适配高分辨率屏幕

## 🕹 操作 Controls

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动 |
| `空格` / `J` | 射击 |
| `Enter` | 开始 / 重新开始 |
| `P` / `Esc` | 暂停 / 继续 |

## 🚀 运行 Run

直接双击 `index.html` 在浏览器中打开即可；也可以通过 GitHub Pages 在线游玩。

## 🎨 预览 Preview

访问部署后的页面地址即可开始游戏。
